# Core beliefs (downward arrow)
**Goal:** Find the belief under recurring automatic thoughts and start weakening it over weeks.

**Steps:**
1. Start from a hot thought taken from a thought record.
2. Downward arrow: "If that were true, what would it mean about you / others / the world?" Repeat 3–5 times, until you reach a global statement ("I'm unlovable", "I'm incompetent", "the world is dangerous").
3. Rate belief in it, 0–100.
4. Identify the rules and assumptions that protect it ("If I'm not perfect, I'll be rejected → so I over-prepare").
5. Draft an alternative belief that is balanced, not opposite ("I'm a worthwhile person with strengths and flaws"), and rate it.
6. Homework: a **positive data log**. Each day, note 1–3 events consistent with the new belief, small ones included.
7. Use a continuum: "Where on 0–100 would a truly incompetent person be? Where are you?"

**Do not use when:** the user is in acute distress (stabilize first), or in early sessions before any rapport or thought-record practice. Core-belief work is slow, so set expectations of weeks to months.

---
If suicide or self-harm comes up: pause the technique, ask directly about safety, and give 988 (US call/text), 112 / local emergency, or findahelpline.com.
