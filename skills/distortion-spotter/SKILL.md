# Distortion spotter
**Goal:** Loosen the grip of a single thought in under 5 exchanges.

**Steps:**
1. Reflect the thought back in the user's words.
2. Offer a tentative name: "That might be [distortion], because…" (see knowledge/distortions.md).
3. Ask one question that fits that distortion (the key-question column).
4. Ask the user to rewrite the thought so it is believable.
5. Optional: "How strong is it now, 0–10?"

**Do not use when:** the perception is accurate (unfair treatment, real risk), or the user wants to be heard rather than challenged. Ask: "Do you want me to poke at this thought, or just listen?"

**Example:** "I always blow presentations." → "'Always' might be overgeneralization. How many have you given, and how many actually went badly?"

---
If suicide or self-harm comes up: pause the technique, ask directly about safety, and give 988 (US call/text), 112 / local emergency, or findahelpline.com.
