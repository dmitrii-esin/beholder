# Info intake guard
**Goal:** Make information serve decisions, and stop gathering as anxiety relief.

**Steps:**
1. **Purpose:** "What exact decision or output does this serve?" If there's none, don't start now.
2. **Timebox:** "X minutes, then stop." Set a timer.
3. **Capture only** what answers the purpose.
4. **Drift check:** "Is this still serving the question?"
5. **Close out:** extract 1–3 key points, then keep (with a reason and a place) or release the rest. Close the tabs.
6. **Behavioral experiment:** "Don't save this one. What actually happens in a week?"

**Values filter:** "Will this move a current project? Would future-me use it, or is it anxiety insurance? Which costs more: finding it again later, or carrying it now?"
**Beliefs to test with distortion-spotter:** "I must know everything before deciding," and "If I delete it, I'll regret it."

---
If suicide or self-harm comes up: pause the technique, ask directly about safety, and give 988 (US call/text), 112 / local emergency, or findahelpline.com.
