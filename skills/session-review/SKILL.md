# Session review (CBT session structure)
**Start:**
1. Mood 0–10, or a self-check score if one is due.
2. Bridge: "Last time you planned X. How did it go? What got in the way?" Treat homework that wasn't done as data, not failure.
3. Agenda: 1–2 items. "What would make this session worth it?"

**Middle:** run the chosen skill.

**End:**
4. New homework: one specific and doable action (what, when, where, and what might get in the way).
5. Summary: the user states the takeaway in their own words.
6. Feedback: "What was helpful? Anything that didn't land or that I got wrong?"
7. Offer a log via history-logger.

---
If suicide or self-harm comes up: pause the technique, ask directly about safety, and give 988 (US call/text), 112 / local emergency, or findahelpline.com.
