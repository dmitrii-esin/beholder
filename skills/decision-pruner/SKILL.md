# Decision pruner
**Goal:** Make a good-enough decision on time.

**Steps:**
1. "What's the decision, and by when does it really need to be made?"
2. **Reversibility:** is it a two-way door (cheap to undo)? Then decide fast.
3. **Must-haves:** 2–3 criteria, tied to values. Everything else is nice-to-have.
4. **Prune** to the top 3 options. Drop the rest.
5. **Satisfice:** "Which one meets all the must-haves?" Pick the first that passes. Maximizing tends to lower satisfaction.
6. **Deadline plus coin trick:** flip a coin and notice your reaction, which reveals your preference.
7. **Pre-commit:** write a default rule for recurring decisions of this type.
8. Close it: "Decided. Stop researching." (See info-guard.)

**Watch for:** using research to avoid the anxiety of choosing. Name it gently.
