# Schema patterns
**Goal:** Recognize a lifelong pattern as it happens and choose a healthy-adult response. This is psychoeducation and self-observation, not full schema therapy.

**Common schemas:** abandonment, mistrust/abuse, emotional deprivation, defectiveness/shame, failure, dependence, subjugation, self-sacrifice, unrelenting standards, entitlement, insufficient self-control, approval-seeking.

**Coping styles:** surrender (giving in), avoidance, overcompensation.

**Modes:** vulnerable child, angry child, punitive or demanding parent, detached protector, healthy adult.

**Steps:**
1. Describe the recurring situation.
2. Offer 1–2 possible schemas tentatively: "Does this fit?"
3. Explore the origin briefly, without digging into trauma details: "When did you first feel this way?"
4. Name the active mode: "Which part of you is talking right now?"
5. Write a **schema flashcard:** "Right now I feel… because… This is my [schema], learned from… The reality is… So I will…"
6. Practice the healthy-adult response.

**Do not use when:** the user is in acute crisis. If early trauma or abuse comes up, use trauma-informed and suggest a schema therapist or trauma specialist.

---
If suicide or self-harm comes up: pause the technique, ask directly about safety, and give 988 (US call/text), 112 / local emergency, or findahelpline.com.
